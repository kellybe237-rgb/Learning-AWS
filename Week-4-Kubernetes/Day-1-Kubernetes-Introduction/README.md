# Day 1 — Kubernetes Introduction

## Objective
Learn the fundamentals of Kubernetes and set up a local Kubernetes environment.

## Work completed
- Set up Docker, Minikube, and kubectl on macOS.
- Started a local Kubernetes cluster with Minikube.
- Verified the cluster with kubectl.
- Deployed a simple Nginx Pod.
- Checked the Pod status and confirmed it was running.

## Key skills
- Kubernetes cluster setup
- kubectl basics
- Pods
- Basic application deployment

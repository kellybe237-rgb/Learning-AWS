# Week 4 — Kubernetes ☸️

This week focused on learning Kubernetes fundamentals and using a local Kubernetes environment to deploy, scale, expose, and configure containerized applications.

## Environment

- macOS
- Docker
- Minikube
- kubectl

## Exercises

1. **Kubernetes Introduction** — Set up Minikube and kubectl and deploy a simple Nginx Pod.
2. **Pods and Deployments** — Create Kubernetes manifests and manage Deployments and replicas.
3. **Services** — Expose applications with Kubernetes Services and access them through a browser.
4. **Namespaces and ConfigMaps** — Organize resources and provide application configuration.
5. **Hands-On Consolidation** — Deploy a multi-container application using Kubernetes manifests.
6. **Advanced Topics** — Explore Kubernetes Ingress and Helm.

## Skills gained

- Kubernetes cluster setup
- Pods and Deployments
- Scaling applications
- Services and application exposure
- Namespaces and ConfigMaps
- Kubernetes YAML manifests
- Application troubleshooting
- Introduction to Ingress and Helm

## Project summary

The project combined containerization concepts with Kubernetes orchestration. I deployed applications, managed replicas, exposed services, configured workloads, and troubleshot connectivity and deployment issues while working toward a multi-container application deployment.

# Day 2 — Pods and Deployments

## Objective
Learn how Kubernetes uses Pods and Deployments to run and manage applications.

## Work completed
- Created Kubernetes YAML manifests.
- Deployed applications using a Deployment.
- Verified Pods managed by the Deployment.
- Scaled the Deployment to 5 replicas.
- Confirmed the desired replicas were running.

## Key skills
- YAML manifests
- Deployments
- Replica management
- Scaling applications

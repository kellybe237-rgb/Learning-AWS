# Day 1 — Basics of GCP and Set Up GCP

## Objective
Learn the basics of Google Cloud Platform (GCP) and prepare the environment for deploying applications.

## Work Completed
- Created and configured a Google Cloud project.
- Installed and configured the Google Cloud SDK (`gcloud` CLI).
- Authenticated the CLI and configured it to work with the GCP project.
- Learned the basic structure of GCP projects and cloud resources.

## Key Commands
```bash
gcloud auth login
gcloud config set project PROJECT_ID
gcloud config list
```

## What I Learned
I learned how to set up a GCP environment, authenticate with the `gcloud` CLI, and configure a project for future cloud deployments.

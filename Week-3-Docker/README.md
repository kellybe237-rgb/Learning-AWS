# Week 3 — Docker

This week focused on learning Docker on an Ubuntu EC2 instance, from the fundamentals through advanced topics.

## Objectives
- Understand containers, images, Dockerfiles, and Docker Hub.
- Install and verify Docker on Ubuntu EC2.
- Manage Docker images.
- Build a custom Docker image.
- Run, inspect, stop, start, and remove containers.
- Work with Nginx containers and modify their web content.
- Practice advanced Docker concepts.

## Exercises completed
1. Docker introduction and installation
2. Docker images
3. Running and managing containers
4. Working with Nginx
5. Docker troubleshooting and management practice
6. Docker workflow practice
7. Optional advanced Docker topics
